What the code review found

  • Every KPI chart in the report is blank. The KPI items say GAAP as reported / USD millions while the observations say gaap / USD, so the filter in research-dashboards.tsx:20 never matches. Segment KPIs also fail because their observations have no segment set.
  • The forecast table is a million times too small. research-dashboards.tsx:44 divides values that are already in USD millions by 1e6 again ("Base capex 0.12").
  • FY2021 is missing because the filing fetch only reads the SEC "recent" filings page. For META that page holds just two 10-Ks, because of heavy Form 4 volume. Older pages (filings.files[]) are never fetched. The full annual history is already in companyfacts, but only quarterly facts are used.
  • Gross margin shows "Unavailable" because META doesn't file gross profit and there's no fallback of revenue minus cost of revenue. ROIC is always unavailable because nothing produces NOPAT or invested capital.
  • The valuation headline numbers are never displayed: current price, probabilities, scenario values, weighted target and expected returns all exist in the artifacts.

Data the new metrics need

  • Available from filings today: all margins, returns (including ROCE and ROIC), SBC ratios, per-share metrics, payout ratios, and debt to EBITDA. Dividends per share can only be approximated, as dividends paid divided by shares.
  • Needs price history: market cap, enterprise value, all price-to-X multiples and the yields. The Yahoo provider and the market_price_bars table exist, but nothing saves META's price history. Each run keeps only a 5-day snapshot.
  • Needs employee count: all six per-employee metrics. The headcount isn't in the captured XBRL; it has to come from the 10-K text (Item 1) or a data vendor.
